
# Contributing to First PR

Thank you for choosing to contribute!

First PR is designed to help beginners learn how open-source contributions work.

Please follow these guidelines before submitting a pull request.

## What can you contribute?

Currently, the main contribution activity is adding your own contributor profile.

Your profile helps document your participation in this project.

## Before contributing

1. Read the README.md.
2. Check the contributors folder.
3. Make sure you haven't already submitted a profile.
4. Use your own GitHub account.

## Adding your profile

Create a Markdown file inside:

`contributors/`

Name your file using your GitHub username:

`contributors/your-username.md`

Use the following template:

```md
---
name: Your Name
github: your-username
---

## About me

Write a short introduction about yourself and what you are learning.
```

## Profile requirements

- Use your actual GitHub username.
- Your filename must match your GitHub username.
- Keep your introduction short and appropriate.
- Do not include passwords, phone numbers, email addresses, or private information.
- Do not include advertisements or referral links.
- Do not submit another person's profile.
- Do not create duplicate profiles.

## Pull Request Rules

- Submit one contributor profile per pull request.
- Use a descriptive branch name.
- Write a meaningful commit message.
- Complete the pull request template.
- Do not modify unrelated files.
- Do not modify GitHub Actions or validation scripts to bypass checks.

## Review Process

Every pull request goes through automated validation and maintainer review.

A successful automated check does not automatically mean your pull request will be merged.

The maintainer may:
- Approve and merge your contribution.
- Request changes.
- Reject contributions that violate the guidelines.

Please be patient and respectful during the review process.

## Need Help?

If you encounter an issue, open a GitHub issue using the available issue template.

We welcome beginners and constructive questions.
