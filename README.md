# ✨ About First PR

Ever wanted to contribute to an open-source project but didn't know where to start?

**First PR** makes that first step easier.

This project is designed to help beginners understand how GitHub contributions work through a simple, practical experience.

You don't need advanced programming knowledge. You don't even need to know Git.

All you need is a GitHub account and a willingness to learn.

### 🎯 What will you learn?

| Skill | What you'll learn |
|:---|:---|
| 🍴 Forking | Create your own copy of a repository |
| 🌿 Branching | Work on a separate branch |
| 📝 Editing | Create and modify files |
| 💾 Committing | Save your changes using Git |
| 🚀 Pushing | Upload changes to GitHub |
| 🔀 Pull Requests | Submit changes for review |
| 👀 Code Reviews | Understand feedback and collaboration |

# 🌱 Complete Beginner's Guide

<div align="center">

**Never used GitHub before? That's completely fine.**

If you're reading this, you may already have a GitHub account.

If you don't, we'll help you create one and get everything ready.

You don't need to know how to code. Follow the instructions step by step!

</div>

## Step 1 — Create a GitHub account

If you already have a GitHub account, skip this step.

1. Visit [GitHub.com](https://github.com/).
2. Click **Sign up**.
3. Enter your email address.
4. Create a strong password.
5. Choose a username.
6. Complete the verification process.
7. Verify your email address.

Congratulations! You now have a GitHub account.

<details>
<summary><b>What is a GitHub username?</b></summary>

Your username is your unique identity on GitHub.

For example:

`https://github.com/your-username`

Your username is `your-username`.

You will use it when creating your contributor profile.

</details>

## Step 2 — Download GitHub Desktop

GitHub Desktop provides a graphical interface for working with GitHub.

Instead of typing commands, you can use buttons to create branches, commit changes, and upload your work.

<div align="center">

<a href="https://desktop.github.com/">

<img src="https://img.shields.io/badge/Download-GitHub%20Desktop-6e40c9?style=for-the-badge&logo=github" alt="Download GitHub Desktop"/>

</a>

</div>

### Installation

1. Open the official [GitHub Desktop download page](https://desktop.github.com/).
2. Download the version for your operating system.
3. Open the installer.
4. Follow the installation instructions.
5. Launch GitHub Desktop.

### Connect your GitHub account

1. Open GitHub Desktop.
2. Select **Sign in to GitHub.com**.
3. Your browser will open.
4. Sign in to your GitHub account.
5. Authorize GitHub Desktop.
6. Return to the application.

You're now connected!

> GitHub Desktop includes Git, so you don't need to install Git separately when using this method.

## Step 3 — Fork First PR

Before downloading the repository, you need to create your own copy.

1. Open the [First PR repository](https://github.com/its-me-kyro/first-pr).
2. Make sure you're logged in.
3. Click the **Fork** button.
4. Select your GitHub account as the owner.
5. Click **Create fork**.

You now have your own copy!

Your fork will look something like this:

`https://github.com/YOUR-USERNAME/first-pr`

## Step 4 — Download your fork

Now let's download your repository using GitHub Desktop.

1. Open GitHub Desktop.
2. Click **File** in the top menu.
3. Select **Clone Repository**.
4. Open the **URL** tab.
5. Paste your fork's URL:

`https://github.com/YOUR-USERNAME/first-pr.git`

6. Choose where you want to save the repository.
7. Click **Clone**.

GitHub Desktop will download your repository to your computer.

## Step 5 — Open your repository folder

1. Return to GitHub Desktop.
2. Select your First PR repository.
3. Click **Show in Explorer** on Windows or **Show in Finder** on macOS.
4. Open the `contributors` folder.
5. Create a new Markdown file.

Name your file using your GitHub username:

`your-username.md`

For example:

`kyro.md`

You can use Notepad, Notepad++, Visual Studio Code, or another text editor.

### Add your contributor information

Copy this template:

```md
---
name: Your Name
github: your-username
---

## About me

Hello! I'm learning open source and making my first GitHub contribution.
```

Replace the example information with your own.

Save the file.

**Important:** Your filename and GitHub username must match.

## Step 6 — Create a branch

A branch lets you work on your changes separately from the main repository.

1. Return to GitHub Desktop.
2. Find **Current Branch**.
3. Click it.
4. Select **New Branch**.
5. Enter a branch name:

`add-your-username`

6. Click **Create Branch**.

Make sure your new branch is selected.

## Step 7 — Commit your changes

1. Open the **Changes** tab in GitHub Desktop.
2. Find your newly created Markdown file.
3. Check that the correct file is selected.
4. Find the summary box at the bottom-left.
5. Enter a commit message:

`Add your-username as a contributor`

6. Click **Commit to add-your-username**.

Your changes are now committed locally.

## Step 8 — Push your changes

Your changes are currently saved on your computer.

To upload them:

1. Find **Push origin** at the top of GitHub Desktop.
2. Click it.
3. Wait for the upload to finish.

Your changes should now appear in your GitHub fork.

## Step 9 — Open your first Pull Request

This is the final step!

1. Open your fork on GitHub.
2. Look for the option to create a pull request.
3. Click **Compare & pull request**.
4. Check that the base repository is `its-me-kyro/first-pr`.
5. Make sure the base branch is `main`.
6. Enter a title:

`Add your-username as a contributor`

7. Complete the pull request template.
8. Click **Create pull request**.

Congratulations! You've submitted your first pull request.

## Step 10 — Wait for review

Your pull request will go through automated checks and maintainer review.

Your contribution may be:

- **Approved:** Your contribution is ready to be merged.
- **Changes requested:** You need to fix something.
- **Rejected:** Your submission does not meet the contribution guidelines.

Once your contribution is accepted and merged, your profile becomes part of the project!

<div align="center">

### 🎉 Congratulations!

You've taken your first step into open source.

</div>

# 🖥️ Prefer using the Terminal?

You can also complete the entire contribution process using Git commands.

This method is optional. If you're a complete beginner, we recommend GitHub Desktop first.

## 1. Install Git

Download Git for your operating system:

[https://git-scm.com/downloads](https://git-scm.com/downloads)

Install it using the recommended settings.

## 2. Open a Terminal

**Windows:**

- Open your repository folder in File Explorer.
- Right-click an empty area.
- Select **Open in Terminal**.

Alternatively, open PowerShell and navigate to your repository:

```powershell
cd "C:\Users\YOUR-NAME\Documents\GitHub\first-pr"
```

**macOS:** Open Terminal from Applications → Utilities.

**Linux:** Open your terminal application.

## 3. Configure Git

Set your Git commit name and email:

```bash
git config --global user.name "Your Name"
git config --global user.email "YOUR-EMAIL"
```

Use an email associated with your GitHub account if you want GitHub to attribute your commits to your account.

## 4. Clone your fork

```bash
git clone https://github.com/YOUR-USERNAME/first-pr.git

cd first-pr
```

## 5. Create a branch

```bash
git checkout -b add-your-username
```

## 6. Create your contributor profile

Create:

`contributors/your-username.md`

Add your contributor information using the template from Step 5.

## 7. Commit your changes

```bash
git add contributors/your-username.md

git commit -m "Add your-username as a contributor"
```

## 8. Push your branch

```bash
git push -u origin add-your-username
```

## 9. Open a Pull Request

Visit your fork on GitHub.

Click **Compare & pull request**.

Check the base repository and branch, complete the pull request template, and submit your contribution.

You're done!

# 📋 Contribution Guidelines

We want to keep First PR welcoming, useful, and organized.

Before submitting your pull request:

- [ ] Read our [CONTRIBUTING.md](CONTRIBUTING.md).
- [ ] Add your own contributor profile.
- [ ] Use your actual GitHub username.
- [ ] Make sure your filename matches your username.
- [ ] Follow the provided Markdown template.
- [ ] Avoid duplicate profiles.
- [ ] Do not include private or sensitive information.
- [ ] Do not modify unrelated files.
- [ ] Do not attempt to bypass automated validation.

**Important:** Passing automated checks does not guarantee acceptance. Every contribution is subject to maintainer review.

# ⚙️ Automated Validation

First PR uses GitHub Actions to validate submitted contributor profiles.

<div align="center">

![GitHub Actions](https://img.shields.io/github/actions/workflow/status/its-me-kyro/first-pr/validate-contribution.yml?branch=main&style=for-the-badge&label=Validation)

</div>

Our validation workflow checks:

- Correct contributor file location.
- Valid GitHub username format.
- Matching filename and username.
- Required profile information.
- A properly formatted introduction.
- No unrelated file modifications.

Automated checks help maintain consistency, while the maintainer handles the final review.
