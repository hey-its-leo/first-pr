
# Code of Conduct

## Our Standards

First PR is intended to be a friendly and respectful environment for everyone.

We expect all participants to:

- Be respectful and considerate.
- Welcome beginners.
- Provide constructive feedback.
- Respect different opinions.
- Communicate professionally.
- Help others learn when possible.

## Unacceptable Behaviour

The following behaviour is not acceptable:

- Harassment or discrimination.
- Personal attacks or insults.
- Threats or intimidation.
- Publishing private information.
- Spam or malicious submissions.
- Deliberately disrupting the project.

## Maintainer Responsibilities

Project maintainers are responsible for reviewing contributions and maintaining a safe, welcoming environment.

They may reject contributions or restrict participation when necessary.

## Reporting

Use GitHub's reporting features to report inappropriate behaviour.

Do not publish private information in public issues.

Thank you for helping keep First PR welcoming.
