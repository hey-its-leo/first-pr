
# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

If you discover a security problem, use GitHub's private vulnerability reporting feature if enabled.

If private reporting is unavailable, contact the maintainer through:

https://github.com/its-me-kyro

Never publish passwords, access tokens, private keys, or sensitive personal information.

## Supported Versions

Only the latest version of this repository is actively maintained.
